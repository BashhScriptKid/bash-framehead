## Source

```bash
fs::checksum::sha256() {
		if runtime::has_command sha256sum; then
				sha256sum "$1" | awk '{print $1}'
		elif runtime::has_command shasum; then
				shasum -a 256 "$1" | awk '{print $1}'
		fi
}
```
