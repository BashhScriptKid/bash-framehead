# `hash::hmac::sha512`

**Signature:** `hash::hmac::sha512(key, message)`

**Module:** [`hash`](../../hash.md) — [Guide](../../guide/index.md)

**Return:** stdout — prints result

## Description

HMAC-SHA512

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `key` | string | Yes | |
| `message` | string | Yes | |

## Source

```bash
hash::hmac::sha512() {
		local key="$1" msg="$2"
		if runtime::has_command openssl; then
				printf '%s' "$msg" | \
						openssl dgst -sha512 -hmac "$key" 2>/dev/null | awk '{print $NF}'
		else
				echo "hash::hmac::sha512: requires openssl" >&2
				return 1
		fi
}
```
