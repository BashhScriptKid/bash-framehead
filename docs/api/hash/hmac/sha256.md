# `hash::hmac::sha256`

**Signature:** `hash::hmac::sha256(key, message)`

**Module:** [`hash`](../../hash.md) — [Guide](../../guide/index.md)

**Return:** stdout — prints result

## Description

HMAC-SHA256

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `key` | string | Yes | |
| `message` | string | Yes | |

## Source

```bash
hash::hmac::sha256() {
    local key="$1" msg="$2"
    if runtime::has_command openssl; then
        printf '%s' "$msg" | \
            openssl dgst -sha256 -hmac "$key" 2>/dev/null | awk '{print $NF}'
    else
        echo "hash::hmac::sha256: requires openssl" >&2
        return 1
    fi
}
```
