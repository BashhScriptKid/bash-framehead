# `runtime::execignore::clear`

**Signature:** `runtime::execignore::clear()`

**Module:** [`runtime`](../../runtime.md) — [Guide](../../guide/index.md)

**Return:** exit code — 0 (true) or 1 (false)

## Description

Clear all EXECIGNORE patterns.


## Source

```bash
runtime::execignore::clear() {
		EXECIGNORE=""
}
```
